ℹ️ Information

Purpose: This load generator simulates user traffic to trigger the memory leak in the checkout-recommendations service.

Normal Load: With 10+ clients, the checkout-recommendations container should run out of memory (OOM) in approximately 30 minutes due to unbounded caching.

🚨 AGGRESSIVE OOM Trigger: The "TRIGGER OOM" button uses 20 parallel workers to send 500 requests with 1MB padding each, triggering OOM within 30 seconds. Each unique cart ID creates separate cache entries with 1MB of padding data.

Monitoring: Watch the real-time memory usage above or check your Kubernetes dashboard/APM tool. Memory should climb rapidly from ~50MB to 500MB+ within 30 seconds.
